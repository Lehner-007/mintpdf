# mintPDF 1.39.4

Gemeinsame Bibliothek josef_basis 0.1.0 lokal eingebunden; vorhandene Schnittstellen beibehalten.

DEB für Linux Mint 22.x, amd64 und Python 3.12 mit PyMuPDF 1.28.2.
OCRmyPDF, Tesseract mit DE/EN-Sprachdaten, wkhtmltopdf, Ghostscript, LibreOffice
und Java sind Pflichtabhängigkeiten. veraPDF 1.30.3 ist im DEB enthalten.

Installation: `sudo apt install ./mintpdf_1.39.4_amd64.deb`.
Die Drittanbieter-Lizenzhinweise liegen im Paket bei. Das Release enthält den
PyMuPDF-1.28.2-Quellstand und seine SHA-256-Prüfsumme zusätzlich zum mintPDF-Quellpaket.
Die technische Paketprüfung ersetzt keine grafische Installationsabnahme.
