# mintPDF 1.39.3

Korrigierte DEB-Abhängigkeiten für Linux Mint 22.x, amd64 und Python 3.12.
APT installiert OCRmyPDF, Tesseract mit DE/EN-Sprachdaten, wkhtmltopdf, Ghostscript,
LibreOffice und Java verbindlich. PyMuPDF 1.28.2 und veraPDF 1.30.3 sind enthalten.

Installation: `sudo apt install ./mintpdf_1.39.3_amd64.deb`.
Die technische Paketprüfung ersetzt keine grafische Installationsabnahme.
